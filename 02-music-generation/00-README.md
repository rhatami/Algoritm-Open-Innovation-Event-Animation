# 02 — تولید موسیقی

<div dir="rtl">

## ابزار

**Suno**

## هدف

ساخت موسیقی‌ای که با فضای رویداد، داستان و حس‌وحال موردنظر هماهنگ باشد.

## فرایند

1. آماده‌سازی متن ترانه.
2. تولید نسخه اولیه.
3. بررسی تلفظ و تناسب موسیقایی.
4. اصلاح متن ترانه، از جمله افزودن یا اصلاح علائم تلفظی در بخش‌های لازم.
5. تولید نسخه نهایی.
6. نهایی‌کردن فایل صوتی پیش از ورود به مرحله زمان‌بندی دقیق صحنه‌ها.

## فایل‌های این بخش

- `style-prompt.md` — ثبت گفت‌وگو با Claude برای پیشنهاد `Style Prompt`.
- `suno-prompt.md` — پرامپت و تنظیمات مورد استفاده برای تولید موسیقی با Suno.

## یادداشت‌ها

این بخش عمداً روند آزمون، ارزیابی تلفظ و اصلاح تدریجی متن را ثبت می‌کند تا مسیر تولید قابل‌ردگیری و قابل‌استفاده برای دیگران باشد.

### تجربه و تنظیمات

- **نسخه Suno:** `V4.5`
- **حالت:** `Custom Mode`
- **BPM:** `105`
- **وضعیت:** نسخه نهایی موسیقی پس از بررسی و اصلاح تلفظ انتخاب شد.
