## روند کار

1. **توضیحات رویداد → شعر اولیه:** اطلاعات رویداد در اختیار **ChatGPT** قرار گرفت تا یک شعر انگیزشی و قابل تبدیل به سکانس‌های انیمیشن پیشنهاد شود.
2. **کوتاه‌سازی:** چون نسخه‌ی اول برای ویدیوی موردنظر طولانی بود، شعر به محدوده‌ی حدود یک دقیقه نزدیک شد.
3. **ویرایش انسانی:** نسخه‌ی نهایی شعر توسط کاربر بازنویسی و انتخاب شد؛ این نسخه مبنای ادامه‌ی فرایند است.
4. **تلاش اولیه برای تولید موسیقی:** شعر وارد **Suno 4.5** شد و چند مشکل تلفظ فارسی مشخص شد.
5. **اعراب‌گذاری و عیب‌یابی تلفظ:** برای کلمات مسئله‌دار، چند نسخه با اعراب و شکل نوشتاری متفاوت آزمایش شد.
6. **نسخه‌ی نهایی برای Suno:** بعد از حذف شکست‌های هجایی نامناسب و تنظیم فاصله‌ی خطوط، نسخه‌ی نهایی برای تولید موسیقی استفاده شد.

## نکته‌ی مهم درباره‌ی این مستندات

متن‌های داخل بخش‌های **Prompt** و **Response** تا حد ممکن به‌صورت دست‌نخورده حفظ شده‌اند تا این پوشه صرفاً یک نتیجه‌ی نهایی نباشد و مسیر واقعی آزمون‌وخطا نیز قابل مشاهده باشد.

توضیحات، عنوان‌ها و ساختار مستندات برای خوانایی بیشتر و مخاطب فارسی‌زبان مرتب شده‌اند؛ اما محتوای اصلی Promptها و پاسخ‌های ثبت‌شده عمداً بازنویسی نشده است.
